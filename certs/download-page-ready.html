If Windows shows a warning when you open it — what to click
  • "Windows protected your PC" (blue box): click More info, then Run anyway. This is normal for a newly released app.
  • "Unknown publisher" or a permission prompt: click Yes. (You can remove this prompt with the optional trust file under "Details" above.)
  • Flagged as a virus (rare — a false alarm some antivirus raise on remote-control software): open Windows Security → Virus & threat protection → Protection history, find the Tether item, choose Allow, then open the file again.

If your Mac blocks Tether the first time — what to do
  • "cannot be opened because Apple cannot check it" or "unidentified developer": open System Settings → Privacy & Security, scroll to the line about Tether, click Open Anyway, then confirm with your Mac password. You only do this once.
  • "Tether is damaged and can't be opened": move Tether into the Applications folder first, then use Open Anyway above.
